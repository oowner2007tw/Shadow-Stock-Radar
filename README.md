# Shadow Stock Radar (影子股票雷達)

![React](https://img.shields.io/badge/React-19-blue)

**Shadow Stock Radar** 是一個結合 **Generative AI (Gemini)** 與 **傳統量化分析 (Quant)** 的高勝率台股分析系統。透過 Google Search Grounding 獲取即時市場數據，結合 Random Forest 演算法進行股價趨勢預測，並透過 6 大因子雷達圖提供多維度的投資決策輔助。

---

## 🚀 核心功能 (Core Features)

### 1. 個股深度分析 (Individual Stock Analysis)
- **六維量化雷達 (6-Factor Model)**：
  - **VIX (恐慌指數)**: 逆勢交易策略，判斷市場貪婪與恐慌。
  - **Margin (融資水位)**: 監測大盤融資餘額變化，判斷散戶動向與籌碼乾淨度。
  - **Chips (籌碼面)**: 外資/投信買賣超與本益比估值。
  - **Topic (題材熱度)**: 結合新聞情緒分析的產業熱度。
  - **Technical (技術面)**: RSI, MACD, 均線排列。
  - **Macro (大盤位階)**: 加權指數季線乖離率。
- **隨機森林預測 (GBM + Random Forest)**：基於歷史數據與量化評分的 10 日股價走勢模擬。
- **AI 投資報告**: 生成法人級別的 Markdown 分析報告。

### 2. 題材影子挖掘 (Theme & Supply Chain)
- **自動化趨勢偵測**: 掃描市場新聞，找出正處於「上升軌道」的熱門題材 (如 CoWoS, BBU, CPO)。
- **供應鏈分級 (Tier System)**:
  - **Tier 1**: 核心龍頭。
  - **Tier 2**: 實質受惠供應鏈。
  - **Tier 3**: 潛力補漲/沾光股。

### 3. 安全存取機制
- **裝置綁定 (Device Binding)**: 使用 Supabase 進行單一裝置綁定，防止帳號共享。

## ⚙️ 安裝與執行 (Setup)

### 1. 克隆專案
```bash
git clone https://github.com/your-username/shadow-stock-radar.git
cd shadow-stock-radar
```

### 2. 安裝依賴
```bash
npm install
```

### 3. 設定環境變數
在專案根目錄建立 `.env` 檔案，填入以下資訊：

```env
# Google Gemini API Key (需啟用 Google Search Grounding)
# 申請位置: https://aistudio.google.com/
VITE_API_KEY=your_gemini_api_key

# Supabase 設定 (用於登入驗證)
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_KEY=your_supabase_anon_key
```

### 4. 啟動開發伺服器
```bash
npm run dev
```

## 🗄️ Supabase 資料庫設定

本系統依賴 Supabase 進行簡單的權限控管。請在 Supabase 的 **SQL Editor** 中執行以下語法以建立必要的 Table：

```sql
-- 建立存取控制表
create table access_control (
  id bigint generated by default as identity primary key,
  passcode text not null unique, -- 登入用的通行碼
  bound_device_id text,          -- 綁定的裝置 ID (首次登入自動寫入)
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 插入一組測試用的通行碼 (例如: 888888)
insert into access_control (passcode) values ('888888');

-- (可選) 啟用 RLS
alter table access_control enable row level security;

-- 開放匿名讀取 (依據您的安全需求調整)
create policy "Allow public read"
on access_control for select
to anon
using (true);

-- 開放匿名更新 (用於綁定裝置 ID)
create policy "Allow public update for binding"
on access_control for update
to anon
using (true);
```

## 📦 部署 (Deployment)

本專案完全支援 **Vercel** 一鍵部署。

1. 將程式碼推送到 GitHub。
2. 在 Vercel 新增專案，連結該 Repository。
3. 在 Vercel 的 **Environment Variables** 設定中，填入上述的 `VITE_API_KEY`, `VITE_SUPABASE_URL`, `VITE_SUPABASE_KEY`。
4. 點擊 Deploy。
